# JIB — البنية التقنية المقترحة

## الهيكل
مستودع موحد (monorepo) يحتوي تطبيقات الهاتف والويب والخادم وقاعدة البيانات.

## التقنيات المقترحة
- Flutter / Dart لتطبيقات الزبون والسائق والتاجر.
- Next.js / TypeScript للوحة الإدارة.
- Supabase / PostgreSQL للمصادقة وقاعدة البيانات والتخزين وRealtime مع Row Level Security.
- Firebase Cloud Messaging لإشعارات الهاتف.
- مزود خرائط للعناوين والتوجيه، بعد اختيار المزود وإعداد المفاتيح.
- Render لاستضافة الخدمات التي تحتاج خادماً مستقلاً أو مهاماً خلفية.
- GitHub Actions للفحوصات والاختبارات التلقائية.

## المجلدات

- docs

## مبادئ الأمان
- مفاتيح الخدمات السرية في متغيرات البيئة فقط، ولا تُرفع إلى Git.
- لا يوضع مفتاح Supabase service role في تطبيقات الهاتف أو المتصفح.
- التحقق من الصلاحيات والأسعار وحالات الطلب على الخادم.
- تسجيل العمليات الإدارية الحساسة.
- تقليل بيانات الموقع والاحتفاظ بها للمدة الضرورية فقط.

## قرارات لم تُحسم بعد
- مزود الخرائط وتكاليفه.
- مزود الرسائل النصية والتحقق من الهاتف.
- بوابة الدفع المغربية وشروط التعاقد.
- سياسة العمولة ورسوم التوصيل.
- متطلبات النشر والحسابات القانونية والتجارية.
